남켓몬 용성지방 — 웹 배포 묶음 (플레이 버전 v2.47)

이 폴더를 통째로 웹 서버(정적 호스팅)에 올리면 index.html 주소로 바로 플레이할 수 있습니다.
설치·로그인 없이 브라우저(크롬·웨일·엣지·사파리)에서 열리고, 태블릿·폰에서는 화면 아래 십자키·A·B 버튼이 나옵니다.

[올리는 방법 예시]
1) Netlify Drop (가장 간단)
   - app.netlify.com/drop 에 접속해 로그인
   - 이 'namketmon' 폴더를 브라우저 창에 끌어다 놓기 → 주소(○○.netlify.app)가 생김
2) GitHub Pages (무료, 주소가 오래 유지됨)
   - GitHub에 새 저장소를 만들고 이 폴더 안의 파일을 모두 올리기(index.html이 맨 위에 오게)
   - Settings → Pages → Branch: main / (root) → Save → 몇 분 뒤 ○○.github.io/저장소이름 주소가 생김
3) 학교·교육청 홈페이지나 서버에 정적 파일로 올려도 됩니다.

[주의]
- index.html을 더블클릭해 컴퓨터에서 바로 열면(file://) 그림·음악을 못 읽어 시작하지 않습니다. 반드시 웹 주소로 여세요.
- 리포트(저장)는 그 기기·그 브라우저에만 남습니다. 학생마다 같은 기기·같은 브라우저로 이어서 하게 해 주세요.
  (시크릿 창에서는 창을 닫으면 저장이 사라집니다.)
- 주소를 아는 사람은 누구나 열 수 있습니다. 링크는 반 학생들에게만 알려 주세요.
- 비공식 교육용 팬게임입니다(시작 화면에 포켓몬 제작사 상표 안내와 감사 문구가 있음). 판매·광고에 쓰지 마세요.

조작: 방향키 이동 · Z 결정 · X 취소/누른 채 달리기 · C 또는 Enter 메뉴
