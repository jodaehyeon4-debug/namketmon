남켓몬 용성지방 — 웹 배포 묶음 (플레이 버전 v2.59)

이 폴더를 통째로 웹 서버(정적 호스팅)에 올리면 index.html 주소로 바로 플레이할 수 있습니다.
설치·로그인 없이 브라우저(크롬·웨일·엣지·사파리)에서 열리고, 태블릿·폰에서는 화면 단추(십자키·A·B·메뉴)가 나옵니다.

[태블릿]
- 세로로 들면 단추가 화면 아래, 가로로 들면 기기에 따라 양옆(엄지 자리)으로 갑니다.
- 대화창·메뉴·예/아니오·배틀의 '싸운다'와 기술 칸은 화면을 직접 눌러도 골라집니다. 들판에서는 눌러도 아무 일 없음(실수 방지).
- '전체 화면' 단추(안드로이드 크롬·아이패드 사파리). 브라우저 메뉴의 '홈 화면에 추가'를 하면 앱처럼 주소창 없이 열립니다.
  주의: 아이패드에서 '홈 화면에 추가'로 연 게임과 사파리로 연 게임은 저장이 따로입니다. 한 가지 방법으로만 하게 해 주세요.

[대화 다 읽기]
- 대화 한 화면이 뜬 뒤 글자 수만큼(한 글자 0.11초, 0.6~4.5초) 지나야 넘어갑니다. ▼가 보이면 넘길 수 있어요.

[올리는 방법 예시]
1) GitHub Pages — 이 폴더 바깥의 CLAUDE.md를 Claude Code가 읽고 대신 올려 줍니다.
2) Netlify Drop — app.netlify.com/drop 에 로그인해 이 'namketmon' 폴더를 끌어다 놓기
3) 학교·교육청 서버에 정적 파일로 올려도 됩니다.

[주의]
- index.html을 더블클릭해 컴퓨터에서 바로 열면(file://) 그림·음악을 못 읽어 시작하지 않습니다. 반드시 웹 주소로 여세요.
- 리포트(저장)는 그 기기·그 브라우저에만 남습니다. 학생마다 같은 기기·같은 브라우저로 이어서 하게 해 주세요.
  (시크릿 창에서는 창을 닫으면 저장이 사라집니다.) 주소가 바뀌어도 저장이 이어지지 않으니 주소는 한 번 정하면 그대로.
- 주소를 아는 사람은 누구나 열 수 있습니다. 링크는 반 학생들에게만 알려 주세요.
- 비공식 교육용 팬게임입니다(시작 화면에 포켓몬 제작사 상표 안내와 감사 문구가 있음). 판매·광고에 쓰지 마세요.
